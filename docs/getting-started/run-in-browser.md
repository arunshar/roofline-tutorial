# Run in Your Browser

By [Arun Sharma](https://arunshar.com) and [Claude Code](https://claude.com/claude-code)

Each lab page shows these two buttons in its top right corner:

<span class="run-btn colab">Open in Colab</span> <span class="run-btn binder">Launch Binder</span>

## Google Colab (recommended)

1. On a lab page, click **Open in Colab**. Colab loads the notebook from the course's GitHub repository.
2. Run every cell with **Runtime → Run all**. To run one cell at a time, press <kbd>Shift</kbd>+<kbd>Enter</kbd>.
3. Running the first cell downloads the course's helper module in a few seconds.
4. Colab discards your changes when the session ends. Keep them with **File → Save a copy in Drive**.

:::{tip}
The labs run on the default CPU runtime. Leave the runtime type as it is, because a GPU
runtime would use up your quota and the labs would not run faster.
:::

A Colab session can restart without warning. If it does, run the first cell again.

## Binder (no account)

1. On a lab page, click **Launch Binder**. [mybinder.org](https://mybinder.org) starts a
   server for the course and opens the notebook in JupyterLab.
2. Run every cell with **Run → Run All Cells**.

Binder is free and needs no login. A launch takes several minutes when Binder has to
rebuild the course image, and the server stops after about ten idle minutes. Save your
work with **File → Download** before you close the tab.
